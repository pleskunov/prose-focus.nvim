*prose-focus.txt*  Focus on the sentence or paragraph under the cursor

                                                        *prose-focus*
Pure Lua prose dimming for Neovim 0.11+. No external runtime dependencies.
See README.md for installation, options, text rules, and validation status.

SETUP                                                   *prose-focus-setup*
>lua
    require('prose_focus').setup({ mode = 'paragraph', dim = 0.60 })
<
COMMAND                                                 *:ProseFocus*
    :ProseFocus [toggle|enable|disable|sentence|paragraph]

No argument means toggle. Choosing a mode does not enable a disabled plugin.

COLORS                                                  *prose-focus-colors*
Automatic dimming mixes global Normal foreground toward its background.
Transparent/terminal-palette fallback: Comment. To use a theme group directly:
>lua
    require('prose_focus').setup({ highlight = 'Comment' })
<
After manual highlight changes:
>lua
    require('prose_focus').refresh()
<
TEXT RULES                                              *prose-focus-rules*
Blank lines separate paragraphs. Sentence endings: ASCII . ! ? followed by
whitespace, optionally after ) ] " '. Trailing whitespace belongs to the
preceding sentence. Abbreviations are not recognized. Paragraph scan overflow
falls back to the current line. Cursor on a blank line focuses that line only.

See |nvim_set_decoration_provider()| and |nvim_buf_set_extmark()|.
